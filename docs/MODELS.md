# Workspace model settings

Evidence mode is the default and makes no model requests, even if provider credentials exist in the server environment. A workspace owner can select evidence, OpenAI Responses, native Anthropic Messages, an OpenAI-compatible endpoint, or Ollama through Model settings. Saving settings does not invoke a model. The separate **Test saved connection** button sends a fixed short prompt to the saved provider and may incur usage. It never sends matter documents.

Workspace credentials and settings are encrypted with AES-256-GCM in SQLite. Encryption authenticates the workspace ID. The server stores the 32-byte encryption key in `DATA_DIR/model-key`; preserve it with database backups and restrict access to that directory. API responses expose only whether a key is present. Blank key input retains an existing workspace key for the same provider; switching provider requires entering the new provider's key. Resetting settings removes the workspace profile and restores operator environment defaults.

Compatible base URLs should include the API prefix, such as `https://example.com/v1`; the server appends `/chat/completions`. Ollama defaults to `http://127.0.0.1:11434` and uses `/api/chat`. Workspace endpoints must resolve exclusively to public IP addresses. Loopback is allowed only in personal mode (`COUNSEL_PERSONAL=true`) or with explicit operator opt-in (`MODEL_ALLOW_LOOPBACK=true`). Private LAN, link-local and metadata addresses remain blocked. Each actual connection resolves again and pins validated addresses; redirects are not followed. Saving may resolve endpoint DNS but does not make an HTTP provider request.

Context and output token budgets are configurable. Input uses a conservative UTF-8 byte estimate plus per-message overhead, rather than a model-specific tokenizer. Oversized requests fail before invocation without silently truncating source text. Set limits within the actual provider model's capabilities. Successful generation returns provider, model, elapsed milliseconds, configured budgets and provider-reported input/output token counts. Missing counts are `null`; these are not billing estimates. Caller AbortSignals cancel provider requests and a 90-second timeout applies. Responses are buffered, not streamed, and limited to 2 MiB.

Server integration: register `createModelSettings(app, db, security)` after authentication/CSRF middleware. Use the returned `configuration()` and `generate(messages, {signal})` methods inside workspace context. Load `/models.js` in the browser and expose `openModelSettings()` to workspace owners. Routes are owner-only `GET`, `PUT`, `DELETE /api/model-settings` and `POST /api/model-settings/test`.

The automated tests use real Express routes and mocked provider boundaries. They verify encryption, owner/workspace isolation, explicit invocation, native request/response conversion, token budgets, cancellation and address checks. They do not establish live provider access or model quality.
